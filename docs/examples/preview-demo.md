# Markdown Preview

通过目录浏览 Markdown 文档 ，查看代码高亮 、数学公式和流程图 。阅读主题自动跟随系统外观 。可切换源码 ，查看当前文档的 Markdown 原文 。

## 丰富的 Markdown 排版

| 功能 | Markdown 写法 | 阅读体验 |
| --- | --- | --- |
| 文字样式 | **粗体** 、*斜体* 和 `行内代码` | 快速识别重要内容 |
| 表格 | 清晰的行与列 | 直观对比结构化信息 |
| 实时预览 | 在编辑器中保存修改 | 继续阅读更新后的文档 |
