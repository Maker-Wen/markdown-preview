# Markdown 增强预览测试

这是一份用来测试“点击普通 Markdown 文件后会打开哪种阅读界面”的示例文档。

> 表格和流程图也可能被原生预览支持，不能只凭它们显示正常就判定进入了增强阅读器。

## 1. 阅读界面

观察页面是否出现 Markdown Preview 的文档列表、完整目录以及阅读主题切换。

### 测试步骤

- [ ] 直接点击这份 `.md` 文件链接。
- [ ] 检查打开后的阅读界面。
- [ ] 关闭文件标签，再点击同一个链接。
- [ ] 检查重新打开后是否仍是增强阅读界面。

## 2. 表格

| 功能 | 示例 | 观察内容 |
| --- | --- | --- |
| 强调 | **粗体** 与 *斜体* | 文字样式 |
| 行内代码 | `preview(document)` | 代码背景与字体 |
| 标题目录 | 本文各章节 | 目录是否完整、能否跳转 |
